# Sample configurations

`microsoft-dhcp-realistic-large.xml` is a synthetic Microsoft DHCP export for testing the Config Workspace with a realistically sized estate. It contains 12 IPv4 scopes, 3 IPv6 scopes, 300 reservations, scope and server options, policies, exclusions, and failover relationships.

All addresses use documentation ranges, all names use reserved `.example` domains, and all identifiers are generated. The file contains no production or personal data.
