# Support

DHCPulse is a community-maintained planning tool and is provided without a service-level agreement.

- Use GitHub Discussions for usage questions and planning-model clarification.
- Use the issue forms for reproducible bugs and focused feature requests.
- Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities.

Do not submit real customer configurations, lease databases, addresses, client identifiers, credentials, or secrets. DHCPulse does not provide emergency response, production change approval, or vendor support.
