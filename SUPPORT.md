# Support

DHCPulse is a community-maintained planning tool and is provided without a service-level agreement.

- Use [GitHub Discussions](https://github.com/bifrost0x/dhcpulse/discussions) for usage questions and planning-model clarification.
- Use the [issue forms](https://github.com/bifrost0x/dhcpulse/issues/new/choose) for reproducible bugs and focused feature requests.
- Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities.

Include the DHCPulse release, browser, detected source format, and the smallest synthetic reproduction. For import problems, describe the unsupported construct instead of attaching a production configuration.

Do not submit real customer configurations, lease databases, addresses, client identifiers, credentials, or secrets. DHCPulse does not provide emergency response, production change approval, or vendor support.
